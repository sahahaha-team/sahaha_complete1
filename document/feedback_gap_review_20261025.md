## 2. HTML 수집과 연락처 파일은 어떻게 다른가

두 방식은 함께 쓰는 구조다.

1. 일반 행정 안내: 공식 페이지 → 원본 HTML 보관 → 메뉴 등 불필요한 부분 제거 → 제목·표·목록을 보존한 검색 자료 → 질문에 맞는 근거 선택·검증 → 답변/출처.
2. 직원 문의: 공식 직원업무안내 및 대표전화 페이지 → 업무·부서·직통/대표번호를 항목별로 추출 → `data/staff_directory.json`, `data/department_contacts.json` → 전화 문의 전용 조회.

즉, 연락처 JSON은 직원 안내 HTML에서 필요한 항목을 가공한 검색용 자료다. 질문할 때 전체 홈페이지를 다시 찾지 않게 하는 피드백과 부합한다. 사람이 번호를 임의로 적어 둔 파일이라는 뜻은 아니다. 다만 갱신에 실패하거나 PC가 꺼져 있으면 오래된 파일이 남으므로 실제 갱신 운영이 필수다.

- `crawler/saha_crawler.py:206`: `PageData.raw_html`에 원본을 보존한다.
- `database_db/database.py:31`: HTML 저장 지원. 구버전 DB에 컬럼이 없을 때 평문 저장으로 돌아가는 호환 경로도 있어 실제 DB 상태를 후속 개발에서 확인해야 한다.
