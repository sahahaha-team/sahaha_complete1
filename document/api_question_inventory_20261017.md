# 실제 상담 API에 보낸 질문 목록

- 자동 회귀584개와 구분한 HTTP 시험 기록입니다. 서로 다른 버전과 반복 요청을 합쳐 정답률을 계산하면 안 됩니다.
- 10/15 이전 모델 기준선72턴과 10/17 b1a7812의 최종140턴(질문 문자열138개)이 있습니다. 최종140턴은 충분S90/확인C21/부분P3/근거 부족I26입니다.
- 후속 개선 완료 때28턴(S15/C1/I12), 마지막 연락처 경계6턴(S6)을 추가 검사했습니다. 28턴에는 반복6턴이 포함됩니다. 이34턴은 Gemma 생성 호출 없이 공식 자료 경로에서 처리됐습니다.
- 앞 단계 API 기록도 아래에 보존했습니다. 단계/버전/반복이 겹치므로 전체 항목 수는 독립 질문 수가 아닙니다.
- 충분S / 필요한 확인C / 부분P / 타당한 근거 부족I / 불필요한 거절R / 오안내W / 실행 오류E를 구분합니다. C/P/I는 충분 답변 정답에 합산하지 않습니다.
- 모델의 실제 출력 계약·취소/회복은 합성 근거를 이용한 별도 검사입니다. 주민 상담 정답 평가로 합산하지 않았습니다.
