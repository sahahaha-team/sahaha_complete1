## 발견한 원인과 변경

1. **일부 정확한 긍정 표현만 허용**: “어 맞아”를 놓쳐 확인 질문을 반복했다. 긍정/부정/불확실 답변과 뒤의 요청 항목을 분리해 해석한다. 부정·모름을 긍정으로 바꾸지 않는다.
2. **확인 후 주제 유실**: “맞으니까 참여방법 알려줘”를 새 일반 신청 질문으로 검색해 구강보건 사업을 안내했다. 확인한 대상은 내부 대화 프로필로 유지하고, 항목만 바꿔도 업무·대상을 함께 전달한다. 이전 문맥이 없으면 어떤 업무인지 확인한다.
3. **대상 단어와 요청 항목 혼동**: “의무관리대상”이 신청방법 대신 대상 질문으로 읽혔다. 확인된 프로필과 주민이 새로 묻는 항목을 분리했다.
4. **일정 항목 누락**: “그럼 일정은요?”가 이전 신청방법 질문으로 남았다. 일정 표현을 요청 항목으로 처리한다.
5. **같은 소방 단어의 다른 교육 차용**: 일정 항목을 고친 뒤 어린이 체험관 시간표를 가져오는 실패를 실제 API에서 발견했다. 확인한 특정 교육 대상은 추가 검색 단어가 아닌 **근거 적격 조건**으로 적용한다. 공동주택 경비책임자 교육에 어린이 체험관 일정을 쓰지 못하게 했다. 새로 명시한 별도 업무는 독립 질문으로 전환한다.
6. **선택지·브라우저 적용**: 해당 대상/일반 주민 선택지를 완전한 질문으로 제공한다. 이전 선택지를 다른 업무 뒤에 눌러도 즉시 여권 등과 섞이지 않는지 검사했다. 최신 JS 문구를 브라우저가 실제로 읽도록 메인·위젯의 스크립트 버전도 갱신했다.
